EDITING TIPS
================================================================================
- To edit articles: Edit the content in js/content-data.js
- To edit quizzes: Edit js/quiz-data.js
- To change colors/styling: Edit css/style.css
- To add apps: Add objects to appsData array in js/apps-data.js
- Always refresh your browser after editing (Ctrl+R or Cmd+R)

For detailed instructions, see README.md

TROUBLESHOOTING
================================================================================
"I see a blank page"
→ Try refreshing (Ctrl+Shift+R on Windows, Cmd+Shift+R on Mac)
→ Try a different browser

"Mobile menu doesn't work"
→ Refresh the page
→ Clear your browser cache

"Quizzes aren't saving"
→ They save to your device only (localStorage)
→ Try a different browser if it's not working
